# Nikki Studio · Windows Portable

《无限暖暖》非官方本地家园存档编辑器。解压即可运行，无需安装 Python、Node.js、Git 或 .NET SDK。程序在本机启动服务，并在浏览器中打开三维编辑页面。

## 启动

1. 将 `NikkiStudio-版本-portable-win-x64.zip` 完整解压到可写目录。
2. 双击解压后文件夹中的 **NikkiStudio.exe**。
3. 浏览器会打开 `http://127.0.0.1:8769`。建议使用 Chrome 或 Edge。

启动前，请先退出已运行的源码版或旧版本；它们可能占用同一个本地端口。

请保留整个文件夹，包括 `_internal`，不要只复制 EXE，也不要在 ZIP 内直接运行。当前包支持 Windows x64。

## 首次配置

- 选择包含 `X6Game` 的游戏安装目录。
- 填入与该游戏版本匹配的 AES JSON。
- 选择匹配的二进制 `.usmap` 文件，不能用映射接口的 JSON 元数据代替。
- 资源解析器已随包提供，无需自己编译；原生解压依赖首次初始化可能需要网络。

程序不附带游戏资源、密钥、映射、个人预设或玩家存档。完成校验后，打开自己的家园 JSON 存档。模型和贴图按需转换，第一次加载可能需要等待。

## 编辑与保存

在三维场景或左侧列表中选择家具，在右侧调整位置、旋转、缩放和可用配色。组合可存为本机预设。

首次验证建议使用存档副本，并通过“文件 → 另存为存档”保存新文件。“游戏 → 选择游戏目录”用于浏览器授权存档读写；“保存到游戏存档”会先备份到 `NikkiStudioBackups`，并拒绝覆盖已经被外部修改的存档。

画面是基于当前游戏文件的编辑预览，部分材质、动画、特效与游戏不同。编辑器能导出 JSON，不保证游戏一定接受所有修改。游戏更新后可能需要新的 AES、usmap 或解析适配。

## 退出与缓存

关闭浏览器只会关闭页面，本地服务仍可能运行。先另存为尚未保存的修改，关闭编辑器标签页，再双击 **Exit.cmd** 正常退出默认端口的服务。

- 用户配置、密钥、映射和预设：`%LOCALAPPDATA%/NikkiStudio`。
- 默认资源缓存：EXE 旁的 `cache` 文件夹。
- 缓存与配置分开保存；删除缓存前应退出编辑器，不能把用户配置当作缓存删除。
- **ClearCache.cmd** 会退出同一数据目录的服务，清除全部版本资源缓存并重新启动；密钥、映射、预设和存档保留。旧缓存恢复视图也会被清除，下一次需要重新转换资源。

## 排查问题

- 页面没有自动打开：手动访问 `http://127.0.0.1:8769`。
- 提示端口被占用：检查是否已有另一个 Nikki Studio 实例运行。
- 模型无法加载：检查游戏版本、AES、usmap 与首次原生依赖下载；不要仅凭页面能打开就认定资源兼容。
- 三维页面黑屏：检查浏览器是否支持并启用了 WebGL，以及显卡驱动或云电脑的 GPU 支持。
- 包未做代码签名，Windows 或浏览器可能显示发布者无法验证的提示。请从项目的 GitHub Releases 下载。
