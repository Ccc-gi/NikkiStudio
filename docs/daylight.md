# 精细等级的自然庭院光照

精细等级使用较强的暖色定向日光、较弱的天空与地面补光，以及已有天空生成的环境反射。受光面和背光面有更明显的差异，保留暗部颜色；接触阴影更清晰，离地阴影继续使用 PCSS 软化。

在“显示与资源设置”中调整“太阳方位”和“太阳高度”，可实时改变受光面、高光和投影方向，无须重新导出或加载模型。首次默认方位 75°、高度 35°，之后使用本机保存的设置。“环境亮度”继续控制曝光。

此调整只作用于精细等级。切回标准或轻量时恢复旧版光照参数、太阳方向和选中高亮。游戏模型、纹理、原有材质参数与存档坐标不变；精细等级的选中高亮只添加选中色，保留材质本来的自发光，不再额外增加发光。

这是浏览器实时预览光照，不包含游戏引擎的完整全局光照、材质特效或烘焙数据。高光仍取决于模型已有的金属度、粗糙度和法线，不能仅靠调亮光源恢复尚未解析的材质效果。

验证：`node tests/lighting_profiles.mjs` 检查等级间参数恢复；`node tests/selection_daylight.mjs` 检查选中色、自发光保留与原材质恢复。浏览器使用实际庭院存档检查建筑、木材、金属与植被，并调整太阳方向观察投影变化。
