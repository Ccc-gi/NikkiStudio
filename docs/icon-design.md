# 应用图标

用户确认的方向：暖金色小屋与积木，简洁温暖，沿用界面的奶油白与暖金色。

使用内置 imagegen 工具生成原创 PNG，保存为 `frontend/app-icon.png`；保留透明背景。通过 Pillow 转换为包含 16、24、32、48、64、128 和 256 像素尺寸的 `frontend/app-icon.ico`，用于 Windows EXE 和网页图标。转换不修改原始设计。

## 生成提示词

Use case: logo-brand. Asset type: Windows desktop application icon for Nikki Studio, a warm, approachable 3D home and garden editor. Create ONE finished square icon, not a presentation sheet. Primary request: a simple warm-gold little house built from a few chunky modular building blocks, on a creamy ivory rounded-square tile. The roof and house silhouette should read immediately at 32x32 pixels. A subtle stepped block at the lower side conveys building and arranging. Refined friendly desktop software identity, smooth vector-like shapes, very restrained shallow dimensionality, clean generous negative space and precise edges. Palette: cream ivory tile, honey/warm gold roof and blocks, deeper ochre accents, small soft light highlight. Centered composition, symbol occupies about 72 percent of tile, rounded square tile occupies about 90 percent of canvas. Transparent outside the rounded tile. No letters, no wordmark, no text, no wallpaper, no furniture scene, no ornate foliage, no multiple options, no watermark. This is an original independent app icon, do not copy official game branding. Output 1024x1024 if possible.
