# 精细等级草坪

地面颜色、草叶和小花均由本项目原创代码生成，不使用游戏资源或下载素材。
`frontend/soft_grass.js`、`garden_growth.js` 和 `garden_art.js` 随项目许可证发布。

草团与小花只在精细等级启用，可在“设置 → 场景地面”中单独关闭；地面始终保留。预览地面与草花根部对齐存档 Z=0。标准和轻量等级继续使用原有地面材质。
共享 Canvas 图集包含四种草团、乳白/淡黄/淡粉小花；草团有 13 到 22 片不同宽度、长度和弧度的 Bézier 叶片。
交叉平面增加中间顶点，按植株变化的弯曲方向形成弧线；透明边缘使用 Alpha-to-Coverage 抗锯齿，
按连续色块形成疏密变化，按相机视锥覆盖可见地面。
近处保持完整密度，远处按距离分级降低密度，视野外不生成。
不下载素材，也不逐叶投射阴影。草团数量受预算限制，一次绘制。
草叶接收现有场景阴影，地面采用连续的多尺度色差，避免重复纹理颗粒。

固定种子的连续噪声场控制疏密和长草区域。常规草团约 14 到 39 厘米，
少量长草约 38 到 58 厘米；方向、宽度、弧度和颜色具有个体变化。
花簇在局部区域稀疏出现，配色权重为乳白 70%、淡黄 25%、淡粉 5%。
花头适度高于所在草团的叶尖，共用根部避让范围。
根部锚定世界坐标网格，远处 LOD 选取已有细网格草根，避免相机移动时重新洗牌。
`garden_preview.html` 使用相同生成算法和光照，可单独近看草叶与小花。

水平视角性能：采用视锥裁剪的自适应区块树，远处合并大区块，
避让查询使用空间索引。生成工作按约 2 毫秒的 CPU 时间片分帧执行，
完整生成后再交换显示缓冲，连续移动相机时最多每 100 毫秒启动一次新任务。
草团与花簇共用一次实例绘制，总数最多 24000，花簇最多 400，GPU 只更新实际使用的实例范围。
草叶采用四点深度过滤，不执行 PCSS 遮挡者搜索；家具和地面仍使用原来的 PCSS。
一次加载后的平视回归测试可运行 `node tests/grass_performance.mjs`，
输出为草地更新 CPU 耗时，不代表整场景帧率或 GPU 耗时。

低矮的贴地模型表面包围盒用于避让道路、地板和石块。
避让是保守的几何估算，复杂曲线或倾斜铺装可能留下较宽边缘。
编辑器新增、移除和移动物品后会重新建立避让范围。
草坪仅属于预览场景，不写入存档，不修改模型、贴图或游戏目录。

验证：`node tests/soft_grass.mjs`、`node tests/garden_growth.mjs`。

Windows 下运行 `py -3 -X utf8 scripts/dev_preview.py`，预览地址为
`http://127.0.0.1:8769/save_scene.html?save=new`。
已有本地 Nikki Studio 服务会正常退出，保留配置和缓存。
修改前端后刷新网页并重新打开测试存档即可查看效果。
