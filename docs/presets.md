# 本机预设库

左侧“预设”页保存和管理成组摆放。预设存放在用户数据目录的 `presets` 子目录（默认 `%LOCALAPPDATA%/NikkiStudio/presets`），每个预设一个 JSON。它独立于浏览器缓存和资源缓存，重启、换浏览器或使用“清缓存”不会删除预设；删除用户数据目录仍会删除它们，请定期导出备份。

- **导入预设**：可同时选择多个单个预设 JSON，也可选择“导出全部备份”生成的 JSON。同名或文件名冲突时自动添加编号，保留已有内容。一次最多导入 200 个预设，文件总大小最多 5 MiB；超过限制时请分批导入。
- **导出**：每个预设的 `⋯` 菜单可导出一个文件；“导出全部备份”导出整个库。下载文件可在另一台电脑导入。
- **管理**：按名称搜索，按最近保存、名称或物品数量排序。`⋯` 菜单提供重命名、复制、导出、删除。删除前可取消，已放置进场景的物品不会随预设删除。
- **查看模型**：卡片图片下方的“查看模型”打开独立弹窗，浅色背景和柔和环境照明；左键旋转、右键平移、滚轮缩放，“查看整体”恢复取景。关闭后释放预览场景并恢复主场景绘制，不改变编辑文档、选择或相机。预览使用标准贴图级别，复用当前游戏的模型、材质、染色与基础朝向校准。
- **缩略图**：可见卡片逐个生成 512 × 320 PNG，保存到资源缓存中的 `preset-previews`。按预设物品内容、游戏资源版本、缓存代次与预览渲染版本隔离；重命名可复用，摆放或游戏版本变化后重新生成。清理资源缓存仅清除可重新生成的图像，预设文件保留。模型缺失时用线框标出，并显示缺失 ID；不把不完整预览或材质编译失败的图像缓存为完整缩略图。
- **放置**：点击预设拿起，点击场景放置；放置整组是一条撤销记录。当前游戏缺少物品时，提示缺失 ID 并保留完整预设，不放置残缺的一组。

单个预设格式为 `nikki-studio-preset`、版本 `1`；整库格式为 `nikki-studio-preset-library`、版本 `1`，包含 `presets` 数组。只携带物品类型、染色和相对变换，不携带模型、贴图、AES 或 usmap。导入不接受未知版本、无效编号、无效变换或染色字段；批量中有错误时整批拒绝，避免悄悄丢物品。资源转换失败仍由现有加载提示报告，不删除库里的预设。

验证：`python -m unittest discover -s tests -p 'test_preset*.py'`、`node tests/preset_management.mjs`、`node tests/presets.mjs`。Windows 清缓存验收只操作临时测试目录，不清理实际用户资源缓存。

预览验证另包含 `tests/test_preset_previews.py` 和 `node tests/preset_preview_geometry.mjs`，覆盖图像格式、尺寸、缓存版本、旧图保留、路径校验与横竖视口完整取景。
