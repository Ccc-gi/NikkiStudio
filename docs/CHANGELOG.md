# 0.0.1（首次 Portable 发布）

- 首次使用默认采用系统光标，保留大喵猫爪选项与已有光标偏好。
- 场景地面开关仅控制草团与小花，关闭后保留地面；预览地面与草花根部对齐存档 Z=0。

- 新增 Windows x64 Portable 包，内置 Python、前端依赖和自带 .NET 运行时的资源解析器，解压后运行 `NikkiStudio.exe`。游戏目录、AES、usmap 和个人存档仍由用户提供，首次原生解压依赖初始化可能需要网络。
- 新增暖金色小屋与积木应用图标，接入 EXE、网页标签及界面品牌区域；EXE 添加产品名称与版本信息。
- Portable 默认资源缓存位于 EXE 旁的 `cache`；配置、密钥与预设继续独立保存在用户目录。提供 `Exit.cmd` 正常退出服务，保留 `ClearCache.cmd` 的显式清缓存入口。不同缓存目录的源码实例与 Portable 不再互相复用同端口的服务。

- 预设卡片增加自动缩略图和独立 3D 预览弹窗，使用浅色背景、柔和环境光和当前游戏的模型、材质与染色。可旋转缩放并恢复整体取景；后台只为可见卡片逐个生成，重复静态模型合批。图像按内容、游戏版本及缓存代次保存，清缓存不删除预设。

- 预设库增加多文件导入、单个导出、全部备份、搜索、排序、重命名与复制；同名导入保留两份，未知格式整批拒绝。预设继续独立存于用户数据目录，清资源缓存保留；命名和确认使用页面内弹窗，兼容内置浏览器。说明见 `docs/presets.md`。

- 修复新放置家具因 instanceID 与当前游戏存档冲突，在游戏载入后被替换为其他物品的问题。
- 保存时根据所选当前游戏存档保留类型一致的编号，其余分配高于两份存档及本地历史上限的新编号，并更新 `attach_id`。仅修改输出副本，取消或失败不改变工作区及撤销历史；连接游戏目录后的另存为同样处理。无法读取的游戏历史不在编号冲突检测范围内。
- 新增「预设」：在场景里选中若干物品，一键存成一组放在本机编辑器数据目录（`%LOCALAPPDATA%\\NikkiStudio\\presets\\`，一个预设一个 JSON，可直接备份或拷贝给别人）。预设记录物品类型、染色与相对整组最低点的变换，之后在左面板「★ 预设」页签点一下就拿在手上，跟着鼠标点场景放置；整组落地后仍是一组可拖动的物品，撤销时整组一起回退。这不是游戏内的组合，不写入存档以外的地方。
- 建造合法性不再依赖用户提供的第三方家具数据：新增 `adapters/build_rules.py`，直接从玩家本机的 PaperBin 读出每件物品的合法缩放范围与 Pitch/Roll 许可，随游戏版本自动更新，开源版开箱即用。缩放范围按记录中出现的浮点对判定，对 1342 件已知规则零误报零漏报；旋转按四段记录布局各自读出，正确率 99.5%。读不出的记录标为“待确认”，不做猜测。
- 存档检查补齐染色两项，与上游一致：不支持的色盘（该物品未提供的方案）与同区域染色冲突。色盘列表来自游戏自身的 HomeColor 表（`dyeSchemes`），修正导出会清除不支持的染色。检查维度现为七项，与上游对齐。
- 建造区域多边形与扩建解锁随编辑器内置（5 个区域 + 5 条解锁），此前 `build_area` 始终为空、越界检查只验高度，现已恢复按区域判定。

- 精细等级加入完整 24 小时昼夜系统：时间滑块（0:00–23:45）沿真实太阳弧线驱动光照，可自动循环（一天 1–10 分钟）；关闭后可在“高级”里直接调光源方位、高度、强度、色温与雾浓度，未改动的参数继续跟随时间，切回自动即清除手动覆盖。
- 日落后由位于对跖点的月亮接管直射光，与太阳分立为两盏灯，避免交接时方向翻转；新增星空、月亮实体与蓝调黎明/暮色两个时段，共七个关键帧，午夜处循环闭合。夜里保持皎洁的月光照明：天空深蓝带星，地面由冷银月光照亮，家具在夜间同样清晰。
- 阴影在日月之间交接：任一时刻只有一盏灯投射阴影，`numDirLightShadows` 恒为 1 故不触发材质重编译；交接点落在两盏光强度相等处，阴影强度恰在此淡到 0，切换不可见。避免两盏灯同时投影的开销翻倍，也避免单灯改向导致的投影甩动。
- 天空改为七档程序化绘本贴图在 GPU 上交叉淡化，各档共用同一随机种子以保证云和远山的形状不随过渡变化；环境反射改用只渲染穹顶的小立方体 PMREM，并节流到每 400 ms 一次，拖动时间滑块时天空与直接光逐帧跟手。整体每帧开销约 0.08 ms，天空贴图占 56 MiB 显存。

- 拿起物品的吸附预览支持 M 三轴移动；手柄操作期间暂停鼠标跟随，确认后保留手动偏移，右键可取消本次移动，最终放置才提交存档。保留 R 旋转与 Alt 对齐。
- 单件工具箱放置和抓取支持按住 Alt 对齐目标接触平面中心与水平朝向，兼容不同款模型的基础朝向校准；松开恢复原朝向，Shift 暂停吸附，确认放置后才写入存档。
- 从本机 PaperBin 读取家具名称、预览图引用、游戏分类层级与物品标签，取消分类空返回和统一占位图；缺少目录记录的物品保留 ID，不猜测分类。
- 染色图标改用当前游戏引用；按需解析 Texture2D 与 PaperSprite 图集裁剪，图标缓存按游戏资源版本隔离，保留旧缓存。图集只解码并暂存最近两张。
- 将“仅显示选中物品”移至属性检查器的选中物品操作区，支持单选、多选及切换选择；设置弹窗不再重复显示此项。
- 将显示与资源选项整合为顶部“设置”分类弹窗，区分画面与环境、编辑辅助和资源管理；灰模与未匹配线框收纳到高级诊断。
- 移除石块、特殊物品定位、物品旋转检查、手动映射和朝向校准调试入口，保留默认模型校准；俯视操作移至选中物品面板，全景操作移至视口。
- 删除单件高清加载按钮，贴图质量统一随渲染等级切换：精细保留原始高清，标准与轻量使用现有压缩 Mipmap 的 1024 / 512 上限；非压缩贴图使用已有预览。模型、视角、存档与染色保持不变。
- 精细等级采用自然庭院日光：加强太阳方向与阴影层次，降低均匀补光，保留天空反射；显示设置增加太阳方位和高度调节。
- 精细等级选中家具时保留选中色，取消额外的高亮自发光，避免掩盖材质受光变化；标准和轻量等级恢复原有光照与高亮。
- 精细等级草地加入庭院野草分布：连续的疏密和长草片区，四种原创草团轮廓，以及不同高度、宽度、朝向和弯曲。
- 添加稀疏乳白、淡黄小花与偶尔出现的淡粉小花，草花共用图集和绘制预算；草根固定在世界坐标上。
- 修复平视时草地遍历数万个小区块并同步重建导致的卡顿：改用自适应区块、避让空间索引、分帧生成及完整缓冲交换。
- 限制草团预算与实例上传范围，草叶采用四点阴影过滤；家具、地面及其他渲染等级保持原有阴影设置。
- 仅精细渲染等级启用原创程序草坪：连续柔和绿地、弯曲成簇草叶、自然疏密与草根到叶尖的颜色过渡。
- 按相机可视范围生成草团，远处按距离降低密度，避开低矮铺装及地板；兼容家具合批和编辑后的避让更新。
- 标准和轻量等级的地面及光照保持原有实现，草坪不进入游戏存档，也不依赖游戏模型或贴图。
- 增加 `scripts/dev_preview.py` 启动本地源码预览，保留配置及资源缓存。

# 0.3.0

- 保留原始最高分辨率压缩纹理，传递游戏已有的连续 Mipmap 层级，启用三线性与各向异性过滤，减少远处树叶、木纹及石材的颗粒和闪点。
- 缩小阴影的法线偏移，调整材质 AO 强度，改善家具接触地面时的层次，不改变模型、游戏贴图或存档坐标。

# 0.2.9

- 启用对数深度缓冲，提高相机近裁面并缩小过大的远裁范围，改善贴地表面的深度冲突。
- 仅将程序生成的预览草地下移并设置深度偏移，家具存档坐标保持原样。

# 0.2.8

- 提高天空反射、半球光及侧向补光亮度，减淡阴影，默认曝光调整为 1.1，改善场景暗部。
- 显示与资源设置增加环境亮度滑块（75% 到 150%），实时调整并保存在本机，不重新加载资源。

# 0.2.7

- 将 drei-vanilla PCSS 阴影适配到 Three.js r183 原始深度纹理，修复旧版辅助代码导致的材质着色器编译失败。
- 标准模式使用当前版本 PCF 过滤，精细模式使用原始深度采样的 PCSS，切换模式时重新创建阴影贴图。

# 0.2.6

- 参考 Three.js 环境贴图示例，使背景天空与材质反射统一，减少集中高光；降低直射光反差、法线和 AO 强度。
- 精细模式接入 MIT 许可的 drei-vanilla PCSS 接触软阴影，轻量模式继续关闭投影；深度格式兼容修复见 0.2.7。
- 保留原始模型法线、几何棱角、纹理、金属度和染色数据，不对游戏存档进行修改。

# 0.2.5

- 添加原创程序生成的 360 度云朵天空和多层远山背景，无须下载或捆绑第三方图片。
- 草地增加细微纹理并延伸到家园外侧，避免有限地板边缘破坏场景观感。
- 降低初始全景视角，让天空与地平线进入画面；俯视检查仍可使用视角立方体。

# 0.2.4

- 将环境进一步调整为温馨动画风格：暖奶油色阳光、淡蓝色阴影补光、自然黄绿色地面，保留明暗层次。
- 减轻全景雾感，避免远景整体发白，保持材质纹理及色彩。

# 0.2.3

- 调整默认环境为柔和明亮日光：提高天空及地面反射补光，降低太阳强度和阴影反差。
- 添加无投影的冷色补光、轻微远景淡雾，采用更柔和的天空与草地配色。
- 保留 ACES 色调映射和原始材质颜色，环境调整不影响游戏存档或资源缓存版本。

# 0.2.2

- 修复树木材质错误优先选择默认白色数组的问题，优先绑定真实 Albedo Tex 与 Normal Tex，并保留家具染色数组的优先级。
- 树皮、树干材质不再因物品名称包含 tree 被误判成叶片透明裁剪材质。
- 更新材质流水线版本，保留旧缓存并隔离修复后的资源。

# 0.2.1

- 提升材质流水线版本，重新生成修复后的资源，保留旧版本缓存。

# 0.2.0

- Windows 包内置常驻资源解析器，只挂载一次游戏归档，按场景批量导出需要的模型和材质。
- 支持直接传递原始 BC 压缩贴图给 GPU，保留游戏纹理分辨率，减少解码和 PNG 编码开销。
- 从当前游戏读取染色配置，恢复区域配色，支持编辑、撤销和另存为。
- 按游戏版本、输入文件、解析器和缓存代次隔离资源；更新保留旧版本缓存，明确清缓存时使用新资源地址。
- 补充蓝图组件模型、材质槽序号、纹理数组和父材质解析。
