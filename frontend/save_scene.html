缓存与卸载清理

打开本页时统计缓存…

关闭页面会释放页面内存；磁盘缓存保留。新请求不再把资源长期缓存到浏览器。浏览器清理只影响当前地址，其他端口或浏览器需分别清理。

清理全部缓存 / 卸载工程

先保存存档并关闭其他编辑器标签页。在工程目录运行以下命令。默认只查看；加 --apply 才执行。

.venv\Scripts\python.exe scripts/manage_cache.py status
.venv\Scripts\python.exe scripts/manage_cache.py clear --apply
.venv\Scripts\python.exe scripts/manage_cache.py uninstall --apply

clear：停止服务，清理生成资源。uninstall：同时清理测试产物和源码 Python 编译缓存。配置与预设默认保留；彻底卸载请先导出预设备份、清理此浏览器资源缓存，再为 uninstall 加 --remove-user-data，之后删除工程目录。删除工程会一并移除运行依赖。游戏目录和下载的存档不在清理范围内。

使用帮助

01

直接编辑存档

不连接游戏存档目录，独立编辑与保存 JSON 文件。

  1. 通过文件 → 打开存档，选择自己的家园 JSON 存档。
  2. 完成编辑后，使用存档检查查看可能存在的问题。
  3. 通过文件 → 保存存档或另存为存档保存修改。

无需授权游戏存档目录。三维模型预览仍需完成游戏资源配置。

02

连接游戏并应用修改

读取本地游戏存档，编辑后写回，再在游戏中还原数据。

操作前，先在游戏内备份

将当前家园方案上传到游戏服务器，保存在“自定义方案 1–10”中的一个位置。软件问题或游戏更新可能导致不可预期的结果，请及时更新备份。

  1. 连接游戏目录

    点击顶部的连接游戏目录，选择本地游戏安装目录 InfinityNikki 文件夹。

    没有找到 BuildData，或载入后是空存档？

    进入游戏家园，使用建造能力并点击脱离卡死，让家园存档缓存到本地 BuildData，然后返回编辑器重新读取。

    如果从未执行过此操作，本地可能尚未生成相关文件。退出游戏后，缓存文件也可能暂时存在，但不会一直保留；使用前建议重新执行一次“脱离卡死”。

  2. 载入最新游戏存档

    在游戏存档列表中选择 BUILD_SAVEDATA_*.json，点击载入。执行“脱离卡死”后，若编辑器提示游戏存档发生变化，请重新载入，确认家园内容已正确显示后再编辑。

  3. 编辑、保存并在游戏中还原

    编辑当前存档，或导入其他存档内容，完成检查后点击保存到游戏存档，将修改写入本地游戏存档。

    切回游戏，再次使用建造能力。出现异常退出提示框时，选择还原数据，加载编辑后的内容。

写回前会备份本地原文件，并检查是否被外部修改。若写回被阻止，请重新载入最新游戏存档后再操作。游戏更新后，存档读取与还原流程可能变化。
